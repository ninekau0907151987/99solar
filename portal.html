สรุปคำตอบ 3 สเต็ปที่คุณไจ๋ไจ๋ถาม:

1. กดริชเมนูแล้วตอบเลย

ทำที่ไหน: ในหน้าเว็บ manager.line.biz ➔ ริชเมนู (Rich Menus) ➔ เลือกช่องที่ต้องการ ➔ กำหนดประเภทแอ็กชันเป็น "ข้อความ (Message)" เช่น พิมพ์ว่า "ราคาแพ็กเกจ" หรือ "นัดสำรวจฟรี"

👉 ผลลัพธ์: เมื่อลูกค้าใช้นิ้วจิ้มปุ่ม ระบบจะส่งข้อความนั้นเข้าแชท และบอทหลังบ้านของเราจะจับคีย์เวิร์ดแล้วตอบชุดข้อมูลกลับไปใน 1 วินาทีทันที!

2. สร้างการ์ด (Flex Message)

ทำที่ไหน: ทำได้ 2 วิธี คือออกแบบใน Flex Message Simulator ของ LINE หรือใช้โค้ดหลังบ้านใน /api/line-webhook.js ส่งเป็น Object ชนิด type: "flex"

👉 ผลลัพธ์: จะได้การ์ดสี่เหลี่ยมรูปภาพสวยหรู มีราคา มีปุ่มกด [ขอใบเสนอราคา] [โทรหาไจ๋ไจ๋] สไลด์ซ้าย-ขวาได้เหมือนแอป Shopee/Lazada!

3. ควิกรีพลาย (Quick Reply)

ทำที่ไหน: ใส่ในโค้ดส่งข้อความแนบ "quickReply": { "items": [...] } ใน Webhook ท้ายข้อความตอบกลับ

👉 ผลลัพธ์: จะมีปุ่มแคปซูลลอยเด้งขึ้นมาใต้แป้นพิมพ์มือถือลูกค้า เช่น [☀️ คำนวณค่าไฟ] [⚡ ดูราคา] [📞 โทรหาช่าง] ลูกค้าเอานิ้วกดเลือกได้เลยโดยไม่ต้องพิมพ์!
